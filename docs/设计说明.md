# 12 路锁控板测试配置 App —— 设计说明

依据：`docs/12路锁控板私有通讯协议-20261006.pdf`、`docs/12路锁控板MODBUS-RTU协议-20261006.pdf`（固件 LOCK_12_MODBUS_TIMED_20261006）。文档里的矛盾、不清楚之处和协议限制见 `docs/协议文档说明-20261006.md`。**只为新协议服务**，不兼容旧协议。

## 1. 目标与范围

- 在 Android 11 设备上，对锁控板做两套协议的完整功能测试与配置：
  - 私有协议：0x01 / 10 / 11 / 12 / 14 / 15 / 16（持续与秒定时）/ 18 / 1A；
  - MODBUS RTU：02 / 03 / 05 / 06 / 0F / 10，异常 01 / 02 / 03，广播地址 00。
- 协议没有配置类指令（地址靠拨码，波特率固定 9600）。“配置”指 App 端的内容：通信时序、各通道用途（电控锁 / 灯或继电器 / 未使用）与反馈线、上电输出安全、测试计划、拨码换算和模拟器。

## 2. 架构

```
app（Kotlin + Compose，minSdk 26 / targetSdk 36，目标 Android 11）
 ├─ transport/  USB OTG（usb-serial-for-android 3.11.0）、板载串口（JNI：termios raw、poll、带截止时间的写出与 TIOCOUTQ）
 ├─ app/        AppController：唯一会话（连接序号、扫描、控制、测试、寿命、终端）、ConfigStore
 └─ ui/         连接 / 控制 / 测试 / 终端 / 配置
core（纯 Kotlin/JVM）
 ├─ protocol/   私有帧编解码、流式解析器、类型化指令
 ├─ modbus/     CRC16、请求与回复类型、按“地址 + 功能码 + 长度 + CRC”定位回复
 ├─ client/     LockBoardClient（两套协议共用一个事务引擎）、SafetyPolicy、OutputTracker、CommLog
 ├─ sim/        双协议模拟器（共享输出、定时器、单脉冲任务、反馈，带故障注入）
 ├─ tcp/        TCP 串口服务器
 └─ testing/    TestRunner、EnduranceRunner、报告
```

## 3. 事务引擎（LockBoardClient）

每笔请求按顺序经过：

1. **脉冲节流**：同一块板上，新脉冲任务会替换正在执行的任务。所以任何脉冲请求（0x10/14/15/18、MODBUS 05/0F/0006，不分协议）都要先等到该板的动作窗口结束。窗口从写出完成算起：逐路为“路数 × 单路最长（默认 1400 ms）+ 余量（默认 1500 ms）”，同时脉冲为“350 ms + 余量”。广播脉冲占用所有地址。只有可归属的私有完成回复才能提前结束窗口。
2. **拿到事务锁**，然后依次：迟到隔离（上次超时后的一段时间，期间收到的数据丢弃并记日志）→ 帧间隔 → 清空接收缓冲（上限 64 KiB，超过即报链路错误）。
3. **可选的 requireClean**：等到该“回复键”干净后再写出。
4. **写出前的最终检查**：在锁内重新执行安全策略；登记本次可能上电的通道；记录回复卫生。
5. **写出，然后读取**。读取按 ≤ 50 ms 分片，使用单调时钟截止。
   - 私有回复按“方向 FE、地址、指令、规定的 LEN”匹配；
   - MODBUS 回复按“地址、功能码（或其异常码）、推算长度、CRC”匹配，并且必须回显本笔请求（05/06 逐字节相同，0F/10 起始地址和数量相同，02/03 字节数相同）。
6. **超时处理**：读类请求可自动重试；动作类永不重试，超时记为“结果未知”。

**超时**：查询和立即确认类（私有 01/11/12/16/1A 及全部 MODBUS）用查询超时；私有脉冲类用动作窗口。

**回复卫生**：回复里没有请求标识，而且有些回复的格式完全相同（例如任意两寄存器的 MODBUS 03，以及所有 0x16 ACK）。每个回复键（私有为“地址 + 指令”，MODBUS 为“地址”）记录“脏到何时”：
- 一笔请求写出后没有得到回复（超时、取消、IO 错误、原始监听），该键就在“写出时刻 + 迟到回复最长寿命（默认 10 s）”之前保持为脏；
- 在脏期内写出的请求，其回复标为**归属不明**（不算确认），同时把脏期延长；
- 读回清账、测试中的关键读取，都要先等到键干净（requireClean）。

**回显**：私有方向 02 的帧自动识别为回显。MODBUS 05/06 的回复与请求完全相同，所以由设置项“丢弃发送回显”决定是否先吞掉一份发送回显。

## 4. 安全策略

两套协议、所有入口（控制页、测试、终端）都经过同一道闸门，并在锁内写出前复查：

- **会上电的写入**：私有 0x16 开（持续或定时）、0x1A 的置位、MODBUS 06/10 写 0004 的置位、MODBUS 10 写 0008 且状态为开。允许的前提：未进入 lockDown，**并且**本次连接确认的接线档案快照仍等于当前档案；再满足以下之一：
  - 通道为“灯/继电器”；
  - 通道为“电控锁”，写入是**定时**的，秒数 ≤ 设置上限（默认 0 = 禁止），并且该通道当前不在“可能带电”登记中（防止反复重新定时延长通电）。
- **会把定时变成持续的写入**一律拒绝：单独写 0005，或写 0005 而不同时写 0004（MODBUS 手册第 13、15 页）；单独写 0007（作用不明）。保留高半字必须为 0。
- **广播**（MODBUS 地址 00）：不允许任何上电写入；广播脉冲须二次确认。
- **终端**：真实总线上每次只能发 1 个完整帧（私有 DC 02 帧，或 CRC 正确的 MODBUS 请求），并且同样经过上述检查；任意字节只能发给模拟器。
- **修改档案**时删除该地址保存的确认。
- **断开**：lockDown（同时禁止新的开锁脉冲）→ 停止活动 → 事务锁屏障 → 收尾 → 关闭。链路丢失（如拔出 USB）时无法收尾：先关闭传输，让在途事务退出并完成登记，再经事务锁屏障导出“携带状态”。

## 5. 输出登记与收尾（以读回为准）

- 任何会上电的写入，都在写出前登记为“可能带电”。0x16/0x1A 的 ACK 不带通道号，**不用于清除登记**。
- 只有两种方式能清除：
  - **可信读回**：MODBUS 03 读 0004–0005（requireClean，采样和清账在同一笔事务内完成），对应位为 0；
  - **操作者确认**：现场核实后在界面上确认断电（写日志）。
- **收尾**（测试结束、停止、取消、断开）：对每个登记的通道发私有 0x16 关，再读回 0004 确认，最多 3 轮。仍未确认的通道报“可能仍带电”。
- 0004 只是持续输出控制字。实际输出 = 持续 OR 脉冲，所以收尾时还会报告脉冲窗口还剩多长。
- **跨会话携带**：未经读回确认关断的输出、未结束的脉冲窗口和迟到回复隔离期，按总线身份保存，带入下一次连接，连接后自动读回核对。总线身份：模拟器、串口节点路径、TCP 主机和端口、USB 适配器的 VID:PID:序列号。没有序列号的 USB 适配器无法识别，它的登记从不自动带入，以免另一条总线上的零读回误清登记。连接任意 USB 适配器时，连接页会列出其他 USB 身份遗留的输出，由操作者选择“是同一条总线：带入并读回”或“现场已确认断电”。脉冲窗口和隔离期只会增加等待，所以在所有 USB 会话之间总是带入。
- 脉冲窗口在写出**之前**就登记：写入抛错时，帧可能已经到达总线，因此仍按完整动作窗口处理。

## 6. 测试项

| 分组 | 编号 | 内容 | 判定要点 |
|---|---|---|---|
| 在线 | T0 | 私有 0x01 = 02 00，MODBUS 03 读 0001 = 0002 | 任一不符即不合格，跳过该板 |
| 通信 | T1 | 两种协议的版本读取 × N | 首发成功、重试恢复、最终失败分别计数 |
| 一致性 | T2 | 0x12、12 路 0x11、MODBUS 02、03(0002) | 前后两次 0x12 快照相同时才比对 |
| 健壮性 | T9 | 坏校验、半帧（100 ms 后清理）、杂散前缀（首字节非 DC 按 MODBUS 丢弃）、不支持的命令 0x13 | 按文档“不回复”判定 |
| 健壮性 | M7 | 05 写 0000 → 03；功能码 01 → 01；03 读 000B → 02；0008 锁号 13 → 02；0004–0005 保留位非 0 → 03，且输出不变 | 收到指定异常码才算通过 |
| 压力 | T10 | 0x12 与 02 交替 | 成功率阈值 |
| 脉冲 | T3 / M3 | 0x10 / 05 逐路 | 动作前后的反馈；MODBUS 在动作窗口内持续采样反馈；非目标通道误开判失败 |
| 脉冲 | T4 / M4 | 0x15 / 0F 奇偶两组 | 同上（逐路顺序无法观测） |
| 脉冲 | T5 / M5 | 0x18 / 06(0006) | 同上；“同时”只能人工确认 |
| 脉冲 | T6 | 0x14 | 板上有灯/继电器时默认跳过 |
| 输出 | T7 | 0x16 持续开/关 | 读回 0004 |
| 输出 | T8 | 0x1A 全开 → 只留 A（0 位撤销）→ 全 0 | 读回 0004 |
| 输出 | T11 | 0x16 定时 T | T/2 时读回为 1；T + 容差后为 0 |
| 输出 | M6 | 06/10 写 0004、10 写 0008（持续与定时） | 读回 0004 |
| 交叉 | X1 | 私有定时 T 后用 MODBUS 重新定时 2T（后一次生效）；另一路私有定时 T（独立到期） | 读回 |

物理动作（锁弹开、灯亮）可以开启人工确认；没有证据时记为“未验证”，不算通过。

## 7. 模拟器

两套协议共享状态，行为按文档实现：
- 单路先通电 300 ms，再等 50 ms 采样，失败最多重试 3 次；同时脉冲不重试；新任务替换旧任务（旧任务的完成回复撤回）；
- 定时到期自动撤销持续输出；
- 0x15/0x18 零位图立即回复当前反馈，高位非零静默拒绝；
- MODBUS 回复异常 01/02/03，广播只执行不回复，首字节非 DC 的帧按 MODBUS 处理；
- 故障注入：驱动损坏、无反馈、反馈卡开、错接、丢包、坏校验、回显、延迟。
