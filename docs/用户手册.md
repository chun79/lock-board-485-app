# 12 路锁控板测试配置 App 用户手册

本手册写给现场操作人员。适用的 App 版本为 1.0.0，板卡为 12 路锁控板（固件 LOCK_12_MODBUS_TIMED_20261006，支持私有协议 + MODBUS RTU）。

> **安全提示**：在真实总线上，App 会**真的开锁、真的给负载通电**。操作前请确认现场无人靠近柜门，负载可以安全通电。

## 1. 安装

1. 设备要求：Android 8.0 或以上（目标设备为 Android 11）。
2. 把 `lock-board-485-v1.0.0.apk` 拷到设备上，点击安装。系统提示“未知来源”时，允许本次安装。
3. 升级时直接覆盖安装，配置会保留。正式版的签名证书 SHA-256 为 `06a7d600…c7c77b`，与此不同的安装包请勿使用。

## 2. 硬件准备

- **485 接线**：板卡的 A、B 分别接适配器（或串口服务器）的 A、B。多块板串在同一条总线上。
- **板卡地址**：每块板用 4 位拨码设地址，地址 = S1×1 + S2×2 + S3×4 + S4×8（拨到 ON 为 1），有效范围 1–15，全 OFF 无效。同一总线上的地址不能重复。App 的“配置 → 拨码地址换算”可以帮你换算。
- **串口参数**：9600 8N1，App 默认就是这个值，一般不用改。

## 3. 界面

底部有五个页面：**连接**、**控制**、**测试**、**终端**、**配置**。

第一次使用时，建议先在**配置**页填好接线档案（第 4 节），再去连接。

## 4. 配置接线档案（重要）

在**配置 → 板卡接线档案**中，为每块板的 12 路逐一设定：

| 设置 | 含义 |
|---|---|
| 类型：电控锁 | 只允许短脉冲开锁；**禁止持续通电**，否则可能烧坏电控锁 |
| 类型：灯/继电器 | 允许持续通电和定时通电 |
| 类型：未使用 | 不允许上电 |
| 有反馈 | 这一路接了门状态反馈线；没接线就取消勾选，否则开锁测试会判为失败 |
| 名称、标签 | 例如“A 柜上层”“3 号门”，会显示在界面和报告里 |

电控锁默认**不允许**定时通电。确需定时通电时，在“配置 → 上电输出安全”里设一个最长秒数。

## 5. 连接与扫描（连接页）

1. 选择链路：
   - **USB 转 485**：插入 OTG 适配器后点“刷新”，选中它。第一次连接时系统会弹出授权框，请点“允许”。
   - **板载串口**：选择 `/dev/ttyS*` 节点。如果收发器需要靠 RTS 切换方向，打开“内核 RS485 模式”。
   - **TCP 串口服务器**：填 IP 和端口。服务器要设为 TCP Server 透传，9600 8N1。
   - **模拟器**：不接硬件，用于熟悉操作。模拟器的结果不代表实物验收。
2. 点 **连接**，状态变为“已连接”。
3. 点 **扫描总线**，App 会逐个查询地址 1–15，列出在线的板和两种协议的版本，点击一块板就选中它。
   - 文档规定的版本值是：私有协议 02 00，MODBUS 0002。
   - 如果某块板“只有一种协议回复”，说明它和文档不符，请检查固件版本。

### 断开

点 **断开**。如果本 App 开启的输出还没关，App 会先逐路关断，再读回确认，然后才断开。读回确认不了的通道，会提示“可能仍带电”。

### 遗留输出

如果链路意外中断（比如 USB 被拔出），App 来不及关断，就会把“可能仍带电”的输出记下来：
- 重新连接同一条总线时，App 会自动读回核对。
- 如果 USB 适配器没有序列号，App 无法判断它是不是同一条总线。这时连接页会列出遗留输出，请你选择：
  - **是同一条总线：带入并读回**：确认就是原来那条总线时选它。
  - **现场已确认断电**：已经到现场看过、确实断电了才选它。

## 6. 手动控制（控制页）

1. 页面顶部显示当前板的地址、拨码和版本。可以选择控制协议：**私有协议**或 **MODBUS**。
2. **12 路通道卡片**：
   - **开锁**：发出一个开锁脉冲（约 0.35–1.4 s）；**读**：读取这一路的门状态反馈。
   - 灯/继电器通道还有 **开**、**关**（持续通电和断电）和 **定时**（按页面上设定的秒数通电，到期由板卡自动断电）三个按钮。
   - 电控锁通道只有在配置里允许定时通电时，才会显示“定时通电”按钮。
3. **确认接线**：持续通电和定时通电之前，必须先核对屏幕上列出的灯/继电器通道和现场接线一致，再点“确认接线”。每次连接都要重新确认；修改档案后，确认会自动撤销。
4. **读回 0004**：读取板卡的持续输出状态。注意 0004 是“持续输出控制字”，不是物理电平；开锁脉冲期间，输出也可能是通电的。
5. **逐路关断并读回确认**：把本 App 开启的输出全部关掉，并读回核对。
6. **现场已确认断电**：板卡读不回状态时，到现场确认负载已断电后使用。这个按钮只清除 App 里的记录，不会给板卡发送任何指令。
7. **批量操作**：先选择通道（选全部锁、选全部输出、清空），再执行批量开锁或批量输出。
   - 注意：批量输出会覆盖全部 12 路，没选中的通道会被关闭，所有定时也会被取消。

自动测试或寿命测试进行时，手动操作会被禁用。

## 7. 自动测试（测试页）

1. **测试对象**：当前板，或扫描到的全部在线板。
2. **测试项**（按需勾选）：
   - 通信与一致性：T1 双协议通信、T2 反馈一致性、T9 异常帧、M7 MODBUS 异常响应、T10 压力。
   - 脉冲开锁：T3/M3 逐路开锁、T4/M4 一次开多个、T5/M5 同时开、T6 开全部。
   - 输出（只对灯/继电器通道）：T7 持续输出、T8 整体输出、T11 定时输出、M6 MODBUS 输出、X1/X2 跨协议定时。
3. **判定与参数**：
   - 建议在真实总线上勾选“**人工确认物理动作**”。每次开锁或通电后，App 会请你观察并确认锁是否弹开、负载是否通电。没有人工确认时，物理动作只能记为“未验证”。
   - 还可以设置“要求锁反馈确认开锁”、成功率阈值、逐路间隔、等待关门时间等。
4. 点 **开始自动测试**。App 会先列出“即将执行的动作”，确认无误后点“开始”。测试中途可以随时点 **停止**，已开启的输出会被关断并读回确认。
5. **测试报告**：每项结论是“通过 / 警告 / 失败 / 未验证”。可以点“分享 TXT”或“分享 JSON”导出。报告里如果有“可能仍带电”的通道，请到现场确认。
6. **寿命测试**：按“读反馈 → 开锁 → 读反馈”循环，只有“关→开”才计为一次已验证动作。可以设置轮数和每轮间隔；连续 5 次失败会自动停止。

## 8. 调试终端（终端页）

- **私有帧**：填地址、指令和数据段，App 自动计算校验并发送。
- **MODBUS 帧**：填地址、功能码和数据，App 自动加 CRC 并发送。
- **原始 HEX**：在真实总线上，必须是一个完整、合法的帧；任意字节只能发给模拟器。
- 所有发送都要经过安全策略检查。电控锁持续通电、单独写 0005 或 0007 等危险写入会被直接拒绝。广播开锁（地址 0）需要二次确认。
- 日志可以“跟随”最新内容、“清空”或“导出”。

## 9. 配置页其他设置

- **通信时序**：查询超时、重试次数、单路动作最长时间等。默认值按文档设定，一般不用改；连接中修改会立即生效。
- **模拟器**：可以设置虚拟板的地址，并注入故障（驱动损坏、无反馈、反馈卡开、错接），用于演示和培训。
- **恢复全部默认设置**。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 扫描不到任何板 | 检查 A/B 线是否接反、地址拨码是否有效（不能全 OFF）、串口参数是否为 9600 8N1、TCP 服务器是否为透传模式 |
| 两块板回复混乱、校验错误 | 地址可能重复，检查拨码 |
| 提示“回复归属不明” | 更早的同类请求的回复可能迟到了，App 不会把它当成本次结果。稍后重试即可 |
| 开锁结果为“结果未知” | 动作指令超时，App 不会自动重发（避免重复开锁）。请读反馈或到现场确认 |
| 持续通电被拒绝 | 该通道是电控锁或未使用，或者本次连接还没有确认接线 |
| USB 断开后提示遗留输出 | 见第 5 节“遗留输出” |

正式投入使用前，请按 `docs/真机验收清单.md` 在真实设备和板卡上完成验收。
