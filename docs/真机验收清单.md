# 真机验收清单（Android 11 + 固件 LOCK_12_MODBUS_TIMED_20261006）

单元测试和模拟器只证明 App 逻辑正确。以下各项需要在真实设备和真实锁控板上完成，并把结论和报告文件名填在表中。

## A. 链路

| # | 项目 | 方法 | 通过标准 | 结论 |
|---|---|---|---|---|
| A1 | USB OTG 授权 | 插入适配器后连接 | 弹出授权框；同意后能连接；拒绝时有提示 | |
| A2 | USB 拔出 | 灯通道持续开启时拔出适配器，再插回同一个适配器重连 | 显示链路断开，操作被禁用；能再次连接。适配器有序列号时自动读回核对遗留输出；没有序列号时，连接页列出遗留输出，等待操作者处理（记录适配器有无序列号） | |
| A3 | 板载串口 | 选择 `/dev/ttyS*` 后连接 | 节点显示“可读写”；扫描能发现板 | |
| A4 | RS485 换向 | 需要时打开内核 RS485 模式 | 读回的 flags 正确；扫描无超时 | |
| A5 | TCP 串口服务器 | 透传模式 | 两种协议都能扫描到；MODBUS 帧没有被网关拆开 | |
| A6 | 回显适配器 | 打开“丢弃发送回显”后运行 M3/M6 | 05/06 结果正确，没有被回显冒充 | |

## B. 协议行为（对应 `docs/协议文档说明-20261006.md`）

| # | 项目 | 方法 | 记录 | 结论 |
|---|---|---|---|---|
| B1 | 版本 | T0 | 私有 02 00、MODBUS 0002 | |
| B2 | 反馈极性与一致性 | 逐路手动开门、关门，再跑 T2 | 1 = 打开；0x12、0x11、02、03 四种读法一致 | |
| B3 | 位映射 | 单独开第 1、8、9、12 路，对照反馈和实际被打开的锁 | 端子与通道号一一对应 | |

| B5 | 脉冲节流 | 终端连续发两个 05 | 日志中两次 TX 的间隔 ≥ 动作窗口；第一个任务完整执行，没有被替换 | |
| B6 | 异常响应 | M7 | 异常码与文档一致；带保留位的写入整笔被拒 | |

| B11 | 发送节奏 | 0x14 执行期间发 0x12 查询（终端） | 记录查询能否得到回复、0x14 的完成回复是否仍会到达 | |
